## 存储与费用

`Message.context_status` 是有默认值的可选字段，旧 SQLite 密文消息无需回填。新故障状态随消息保存；历史正文不加入故障词。`video_watch_attempts` 仍记录尝试、原因和大小，失败次数不退回每日配额。

搜索成功通常涉及检索、来源筛查、主对话三步，各自按原账本记费；主对话不开放搜索工具。查询失败仍保守保留未知用量，后续生成也必须取得新的预算预留。搜索服务故障不会单独触发聊天接口的 60 秒冷却，全局预算熔断保持不变。

## 本地验证与部署

本次全量测试 **1314 项通过**，Ruff 检查、前端 JavaScript 语法检查、依赖锁检查与容器断网冒烟均通过。测试全部使用 mock，禁止真实外部连接，不花费 Gemini 额度：

```bash
.venv/bin/ruff check src tests
.venv/bin/pytest -q
uv lock --check --offline
docker build -t hakimi-surf:1.1.3 .
```

部署前备份主 SQLite、各会话 SQLite 和 `.env`，保留旧镜像以便回滚。沿用现有 Compose 覆盖文件，尤其 Google Drive OAuth 凭证挂载；只重建后端，不重启上海 NapCat。原 `/admin`、0–30 秒防抖、联网开关和预算配置继续使用 SQLite 中的值。

验收重点：后端健康、WSS 重连与心跳、管理接口鉴权、公开 `/admin` 返回 404；可在后台沙盒查看较长回答是否完整。真实联网会按账本计费，离线测试不代替实际搜索内容验收。
