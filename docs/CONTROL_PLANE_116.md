# v1.1.6：运行热配置与星夜控制台

本版将限流、输出和巡逻配额接入现有管理台与加密 SQLite 配置，扩展用户及分项日预算。管理员无需重建容器即可调整；身份鉴权、SSRF 防护、模型路由、隔离会话和 ACK 投递保持原有边界。

## 热配置与持久化

| 管理入口 | 可调整内容 | 生效方式 |
| --- | --- | --- |
| 回复与联网 | 用户／全局 RPM、队列容量、发送延迟，原有防抖及搜索配置 | 后续入队和发送读取新值 |
| 模型与思考 | Carbon 开关、聊天／Owner／摘要／日记／high 输出 Token 上限，原有场景思考档位 | 后续生成计划读取新值 |
| 巡逻与日记 | 订阅上限、轮询间隔 | 缩短间隔时推进过远的下次轮询时间 |
| 账本与预算 | 日／月、单用户、巡逻、记忆、主动私信、管理测试日预算 | 后续付费调用先校验并预留 |

新增 `limits_policy.py` 定义严格类型和范围，现有 `admin_config` 表增加 `rate_limits`、`generation_caps`、`patrol_limits` 三类加密键值，无需重建数据库。保存时先事务提交，再同步更新内存设置；启动从 SQLite 恢复覆盖值。页面显示当前来源，可明确重置回启动时读取的 `.env`。

旧版预算仅保存日／月字段的行会合并其他环境初始字段后加载。预算接口支持部分字段更新，避免旧调用方覆盖新字段。总累计预算仍由 `.env` 控制；任一相关上限设为 0 会暂停对应付费工作，不会解除限制。预算拒绝审计可区分具体额度类别。

## 控制台与架构图

`/admin` 继续是单个内嵌 HTML，使用内联 CSS、原生 JavaScript 和本地 SVG 图标，无外部字体、CDN 或 Node 构建。15 个模块按运行、对话、记忆、巡逻分组，提供清晰的配置卡片、状态概览、表格空态、深浅主题与移动端抽屉；键盘可用上下方向键、Home／End 切换模块，Escape 关闭导航。

登录口令仅存在页面内存，不写入浏览器存储。只有主题偏好写入 `localStorage`。表格和通知仍以文本节点展示服务端数据；所有管理 API 继续经过 ADMIN_TOKEN 和同源检查。原有表单、私密快照、沙盒、日记与表情功能保留。

[架构图](../architecture.html) 增加控制流：管理台 → 鉴权／校验／锁 → 加密 SQLite → 运行时设置 → 入队、模型、发送及巡逻。预算图展示请求前预留、返回后结算及全局／用户／分项限制，并保留消息主链、差量续链、记忆和 Drive 隔离关系。

## 发布验证

发布执行全量离线测试、依赖锁与 Ruff 检查；使用临时 SQLite 和模拟模型，通过 Chromium 检查全部模块、热配置保存、深浅主题、登录退出、手机排版及导航。浏览器验收不修改生产设置，不调用真实模型。

沿用境外 `docker-compose.yml` 和 `compose.roaming-oauth.yaml`。部署前备份数据库与 `.env`，仅替换后端并保留回滚镜像；境内 NapCat 自动恢复 WSS。`/admin` 仍通过 SSH 隧道访问回环 12141，公网保持 404。
