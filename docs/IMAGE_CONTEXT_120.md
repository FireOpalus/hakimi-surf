# v1.2.0：图片上下文、短期找图与稳定表情协议

[架构图](../architecture.html#image-context) 按当前实现展开图片来源、压缩、筛查、生成和确认入史。保留既有跨机 OneBot、群／私聊准入、Bot 阈值、双轨记忆、差量续链及 v1.1.8 费用结算。

## 群聊上下文闭环

符合群准入、仅因互动策略未直接触发回复的普通成员消息，也可写入有限的门卫上下文。图片没有文字时补 `[附图]`，空白消息不占上下文；已知外部 Bot 不因这条旁听分支获得放行。

助手收到发送 ACK 并确认写入会话后，把已确认的多气泡文字合并成一条 `[哈基米已回复]` 门卫背景，避免下一轮判定不知道自己刚让群友发图。用户纯图片消息按“未说完”处理，采用后台现有的 incomplete 防抖时长，仍受批次最长等待限制；不新增固定等待秒数。

## 当轮图片选择与历史找图

每轮最多两张：先当前批次／引用展开图片，再选邻近上下文；邻近候选中普通图片优先于贴纸，贴纸由 `mface`、非零 `sub_type`／`subType` 或已缓存素材哈希识别。图片来源标注发送者和来源类型，转发作者声明不作为真实身份授权。

当非沙箱请求没有可用图片，且文字提到“刚才那张图”等看图指代时，从同平台、Bot、场景及会话的 HotRing 取候选。时间戳有效时按 30 分钟窗口限制，最多取 20 条带图消息；排除当前批次、已考虑的邻近消息、本机消息及撤回记录。优先匹配被点名者／昵称，L1–L3 再偏向尚未生成摘要的图，同等条件偏向较新消息，最终仍优先普通图且最多加载两张。

历史找图只使用当前进程的短期环形缓存，不扫描其他会话或 Drive。HotRing 默认最多 64 个会话、每会话 200 条、全局 8 MiB；重启、会话清空及容量逐出后，不保证仍能找回原图。已保存的文字摘要可以继续作为背景。

新增找到的图片先过 Decisions 来源筛查，再加入当前动态输入；生成前继续检查来源是否撤回、会话是否有效。带图的自动路由最低提升到 L2；后台显式思考档位仍按既有策略覆盖。没有可用图片时，不会凭空构造图片内容。

## 自适应清晰度与传输边界

| 类型 | 发给主模型 | 门卫缩略图 |
| --- | --- | --- |
| 普通静态图 | 最长边 768 px，JPEG quality 85，`medium` | 最长边 448 px，quality 72，`low` |
| 长宽比 > 2 的静态长图 | 长边 ≤1536 px、短边 ≤768 px，不放大；quality 86，`high` | 最长边 512 px，quality 72，`low` |
| 动图 | 首尾两帧拼接后限制在 1152×768 px，quality 82，`medium` | 按原始宽高比选择 448／512 px，quality 72，`low` |

仍只接受 JPEG／PNG／WEBP／GIF，遵守像素上限、动图帧数／总像素限制及单图 3,500,000 字节上限。WS 取图串行、会话范围缓存与受限 CDN 回退沿用原实现；跨机发送表情继续使用 Base64，不共享本地路径。缺少 usage 时的图片费用估算按 `high` 每张 1120、其他分辨率每张 560 Token 计入回退计算；这不是供应商实际 Token 保证，正常结算仍优先 usage。

解析和兼容转发展开保留最多两张去重图片，超量记录 `truncated` 而非仅因图片多就拒绝整条消息；文字长度、来源权限和其他安全检查仍有效。

## 120 字附图摘要与表情前缀

五维输出的 `image_digest` 上限从 20 扩到 120 字，可保留可见报错、数值及画面要点；仍禁止保存凭证或照抄图片内的权限指令。摘要在安全检查和 ACK 后追加为 B 区历史文字，图片字节不写入会话热史。

表情输出协议留在 A 区静态系统指令，公开群聊／非 Owner 私聊的可用标签放在 C 区 `transient_turn_context.meme_labels`，作为数据而非指令。此次升级改变固定协议，旧链按已有前缀校验失效后从完整上下文重建；此后增删本地表情更新标签，不改变 A 的哈希、不仅因此使 `previous_interaction_id` 失效；输出仍按当前本地白名单校验。Owner 专属私聊、沙箱及非聊天业务不注入这份动态标签名单。

## 兼容与发布

本版不新增 SQLite 表或重写旧账本。`ImageRef.is_sticker` 默认 `False`，旧消息载荷可继续解析；120 字摘要沿用既有历史记录结构。已有 v1.1.8 校正标记保持有效，不重复校正费用。

发布验证覆盖门卫上下文闭环、长图／动图处理、撤回与跨会话隔离、纯图防抖、转发截断、表情增删与续链兼容；并检查数据库副本连续初始化、目标镜像冒烟、管理台及上线 WSS 状态。
