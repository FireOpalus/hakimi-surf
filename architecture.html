01 境内 / 02 境外

哈基米怎样回复，又怎样主动行动？

QQ 消息从境内进入，境外负责判断、记忆与投递。生活引擎则从世界状态出发，先记下可过期的行动意图，到点才决定是否开口或执行游戏目标。两条路径共用模块状态，但各有自己的连接、权限和完成凭证。

01

境内双连接与境外独立管理后台

境内的 NapCat 和执行节点主动连接境外引擎。管理员通过 SSH 进入独立后台，页面发布期间两条 WebSocket 继续由引擎持有。

02

从世界状态到一次主动行动

启动时，引擎从模块目录的 .gitmodules 读取已安装仓库，逐个加载 plugin.py，并把返回的模块登记到 ModuleRegistry。平台模块声明动作、就绪条件与调度设置，后台提供各自的开关。随版本交付的系统模块从 system_modules/ 按依赖装载，目录直接展示运行状态。日记、Drive 同步、数据库备份、分身镜像、群记忆镜像和 Owner 只读记忆各自装载。世界引擎读取登记的策略来规划时段、检查次数和执行意图。WorldStateManager 保存当前模块、专注、心情、精力和无聊度。

LOW · qq_social

QQ 社交

汇总传输状态、活跃群和缓冲条数。这里不读取 Owner 私聊正文。

MEDIUM · bilibili_surf

B 站冲浪

境外组织巡逻；境内节点在线且启用委派时，可由境内代采。传感摘要区分采集状态和最近记录。

HIGH · minecraft

Minecraft

境外保存最新的境内游戏快照。桥已连接、游戏已配置、角色已进服和暂停是四种不同的信息。

03

一次冲浪，怎样影响游戏和聊天

视频分析有三种证据：字幕与文字、原片影音、关键帧。分析结果可以成为游戏灵感；视频链接本身不能直接指挥游戏。

04

一条 QQ 消息，从收到到记住

收到消息、决定回复、收到发送回执是三个不同的时间点。在同一群里看到消息，不等于 Bot 已经开口；生成了文字，也不等于对方已经收到。

CONTEXT / A → B → C

什么可以进入本次请求

A：静态前缀
共享规则、人设、自我身份和允许的动作协议。好友私聊与群聊使用公开人设。
B：会话热史
按会话组织稳定的消息历史；助手发言以已确认投递的内容为准。
C：动态尾部
当前发言、图片、引用、检索证据、召回记忆，以及适用时的 world_state_summary、jit_proactive_intent。它们都是数据，不能提升权限。

前缀与链缓存上下文装配与裁剪

MODEL / PRIVACY

谁可以看到什么材料

门卫是 gemini-decision-1。私聊默认高隐私，走付费门卫；低隐私会话可走已配置的免费门卫，回退按策略决定。生成统一选择 Hydrogen、Neon 或 Carbon。平台和常驻系统模块各自声明思考场景。开发者 API 与 Vertex 使用选定模型，记忆 Flex 和视频 Files 按实际模型计量。

允许云端短续链的聊天，按会话、模型、前缀和历史版本复用已确认标识；清空、裁剪、失效后重建。生活引擎的临场发言使用当前上下文，不串接现有聊天链。

展开：群内准入、图片与出站约束

外部 Bot 有三条路径

本地硬拦截、按配置阈值评估、或真实 Owner 邀请的限次窗口。不能靠聊天文本伪造邀约或权限。普通群成员按群白名单进入，私聊好友名单只决定私聊准入。

好感度与身份不是同一件事

七级能力表限制普通成员可触发的功能；Owner 私聊依赖协议身份和私聊场景，不由好感度或昵称解锁。公开群用简短的群聊语气；真实 Owner 在群里也不会带入私聊笔记。

图片与文件

从当前批次、引用或邻近群消息选择有关图片；通过 OneBot 或受限网络路径取图，检查大小和像素，必要时切片。单轮最多两个模型图片槽；读取的图片、文件与卡片都要经过来源筛查。跨容器发送表情用本地白名单和 base64://。

逐气泡投递

群内提及目标与本地允许集合匹配；被拦、主动弃答、生成后未发、已送达和结果不确定分别记录。已知不确定的发送不盲目重试。

05

会话库、只读记忆和备份的边界

境外持有权威数据。游戏快照是运行背景，聊天热史属于单一会话，Owner 镜像是给本人阅读的导出。这三种材料不会因为都存于境外就变成群聊的共享记忆。

SQLite / hakimi.sqlite3

全局调度与账本

world_state
单行快照与最近主动活动时间。
scheduled_intents
目标模块、投递范围、到期时间、门控条件、状态；保存意图而非预写聊天台词。
life_plan_runs / life_agenda_items
按本地日期唯一登记晨间规划。行程项关联执行队列，日内调整和事件消费在同一笔事务提交。
global_events
模块里程碑、重要性和消费状态；规划器读取未消费事件。
group_proactive_cooldown
各群最近主动发言时间。配置、预算、出站回执与 Owner 私信队列也由主库存储。
SQLite / sessions/{group,private}/

每个群、每个私聊各自一本

按平台、机器人与会话身份派生文件键，敏感载荷加密。入站收件、热消息、折叠版本、确认回执与续链都有各自的记录。

热史裁剪先封存冷分片；后台按同一会话和 epoch 合批，筛查后提炼为画像与编年史，再入对应会话库。清空或版本变化会使过期的归档结果失效。

允许的方向：Owner 私聊可回顾已参与的公开群互动；群聊不能反查 Owner 的私聊库或桌面笔记。

从后台判断系统正在做什么

管理请求经 SSH 隧道到回环端口；API 校验 ADMIN_TOKEN、Host 和浏览器来源。下面列的是面板读数的依据，不能从这张离线图推断线上健康状态。

/admin/api/life

生活引擎与模块调度

分开看 NapCat、境内节点（含心跳、RPC 错误与 B 站委派）、MC 桥与游戏连接。后台按登记动作显示执行模块、接收范围、就绪原因与路由模式。票据列出来源、关联事件、结果及旧路由对照。可热调共用规划参数。各模块面板提供本模块登记的执行设置，配置由引擎保存并通知调度器。后台还可取消待执行意图或提交受限的 MC 目标。手动触发规划、门控和游戏动作受频控与操作锁约束。

“今日主动”怎样计数？

按机器人当地自然日统计世界引擎完成或结果不确定的自主聊天与 B 站小号巡逻。每日报告有独立的一次机会，游戏目标另行统计。

“上次主动”来自哪里？

JIT 发送和常规 Owner 主动私信确认后会更新世界状态。若旧库没有该时间戳，面板取已发 Owner 私信与已完成社交意图中的最近记录作为回退。

/admin/api/sessions · /admin/api/notebook

会话与 Owner 桌面桥

会话面板分列热窗口条数、旧滚动摘要字数、双轨是否就绪，以及未删除的双轨条目数和正文总字数。旧摘要为零，不能据此判断记忆库为空。

“小本本关闭”不等于桌面桥关闭

Notebook 与 Antigravity 只读挂载分别报告。桌面桥启用时，受保护的接口返回脱敏常驻备忘预览、索引片段数和最近活动；私人备忘正文不进入普通群聊和境内节点的状态数据。

世界引擎统一安排巡逻与主动私信

世界引擎用 bili.patrol 安排小号巡逻，用 qq.speak 发起聊天。qq.owner_digest 在当日可发送时段结束前安排一次日报，与手动汇报共用 SQLite 回执。QQ 负责向 Owner 投递、离线暂存和零 Token 运维告警。

一笔模型费用，从预留到核对

SQLite 事务预留 → 发起请求 → 按供应方用量结算或标注估算 → 按日期、模型、来源与实际思考档汇总。输入、缓存、输出和思考 Token 分开记录；自主聊天与巡逻的次数单独统计。

可选外部检索独立取证并筛查来源，再把材料放入 C 区；搜索次数单独计量。GCP 账单与用量同步也是可选的核对途径，不能把本地未知模型费用直接归作 Drive 费用。
