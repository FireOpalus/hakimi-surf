01部署与进程边界

当前默认拓扑 · OneBot v11 反向 WebSocket

兼容接入与部署依据 代码支持的其他入口，不代表默认公网开放

兼容 OneBot HTTP、正向 WS 和官方 QQ Webhook。HTTP 回调走 /webhooks/onebot 或 /webhooks/qq，分别验证 HMAC 或 Ed25519；默认 Nginx 模板只暴露反向 WS 路径。

反向 WS 验证 Bearer Token、Self-ID、Universal 角色，并经 get_login_info 再核对身份。连接可接管旧会话，带心跳和受控 RPC。

app.py · onebot_transport.py · 后端 Compose · NapCat Compose · Node 镜像示例 · Nginx WS 模板

Owner 专属背景仅在对应私聊加载。可选记忆先让出预算；默认以本地估算的 1,800 Token 限长，为动态尾窗留出余量。
