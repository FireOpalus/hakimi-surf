进程外远程插件 × 7

独立容器经 plugin_bus 内部 WebSocket 与双向有界分块 Blob 总线接入引擎

统一隔离与分层总线契约：引擎侧 src/hakimi/plugin_bus/ 拆分为无环分层子包（protocol / blob / proxy / ai_gateway / domain_bridge / bus），经 Wave 1–4 加固实现非阻塞 _reader() 有界每会话派发、凭据变更 TOCTOU 串行化与每插件 KV 键上限；5 个轻量容器共享 hakimi-plugin-common:latest 镜像，全部 7 个远程容器执行只读根文件系统（read_only）、cap_drop: [ALL]、no-new-privileges、非 root（10001:10001）、cpus 限额、轻量 /proc 健康检查与零宿主机卷挂载，经 ws://hakimi-bot:12141/ws/plugin 令牌鉴权连接。控制面维持 256 KiB WS 帧上限；大载荷（工具结果、入站媒体 media.fetch 与翻唱歌曲 delivery.send_voice）经双向有界分块 Blob 协议（128 KiB 分片 / 40 MiB 硬限 / SHA-256 校验 / 60s TTL）传输。外置工具容器离线时默认平滑回退主引擎，支持按需启用严格仅远程模式。

一次对话共享哪些服务

  1. 协议准入

    经 PlatformPolicyHooks（未知平台 fail-closed）按真实身份、会话名单、Bot 策略与作息处理来信；确定性斜杠/前缀指令经 CommandRegistry 在入模前完成协议层 Owner 鉴权并执行。

  2. 门卫与上下文

    门卫评估接话和安全。A 放静态人设，B 放会话热史，C 放当轮发言、media_turn 筛选的图/语音/文件、获准召回的记忆与工具资料。

  3. 模型与输出审核

    模型网关按场景、隐私策略及预算路由请求。生成结果经审核并转换为气泡、引用或本地表情等动作。

  4. Outbox 与 ACK

    投递前复核权限和时效。助手正文按已确认的发送回执入史，审计记录丢弃、拦截、成功或待确认结果。

物理分域语义记忆与存储加固
Zone 1 会话隔离库（sessions/{kind}/{key}.sqlite3）：热史与双轨编年史按会话物理隔离，只读查询走 SessionManager.database(readonly=True) 零写锁路径，平滑兼容历史 192 维哈希与 Vertex AI 优先（gemini-embedding-001 768 维 float16 E1）Fernet 密文语义向量；Zone 2 Owner 语义库（owner_memory.sqlite3）：独立 0600 加密库，支持双时态历史演进（valid_from/valid_until/superseded_by）与 1-hop 实体图谱扩展，经不可伪造 MemoryCapability 强鉴权并纳入独立加密备份；Zone 3 云端只读桥（OwnerCloudMemory）：严守 Antigravity_Memory 只读红线，仅在本地加密缓存分块向量。主库、会话库与 Owner 语义库均具备热点索引、事件驱动唤醒、周期保留清理与 PRAGMA wal_checkpoint(TRUNCATE)。
模型续链
符合条件的主对话按模型与历史版本复用已确认的交互标识。收到发送回执后才提交新的本地续链。
图片、语音与文件
由 media_turn.py 从当轮、引用、转发和邻近消息筛选媒体（普通图优先于贴纸，转发限 24,000 字/2 图/2 文件并拦截凭据泄露）。图片经大小、像素与来源检查；QQ 语音经 get_record(out_format="mp3") 拉取（仅认 base64 或公网 IP 钉死 HTTPS，禁读本地路径），由 audio_media.py 调 ffmpeg 转为 16 kHz 单声道 32 kbps MP3 后以原生 AudioContentParam 直传 Gemini（取消 NapCat ASR，不触发文本斜杠指令），同轮 0 额外调用附带 audio_gist 写入会话历史与双轨记忆；富文档解析与长文卡片渲染优先交由独立容器 doc_render（纯内存防炸弹），离线平滑回退内核。
Owner 私有背景与单向共鸣边界
协议身份、is_verified_owner_scope 与不可伪造 MemoryCapability 决定私有数据的跨平台可见范围，IdentityService 与 AffectionManager 实现无锁反转的跨表原子合并；ShareResonanceEngine 对公开见闻分别探测 Owner 记忆域与各活跃群自有 DualMemory（严格单向零串流、Fernet 作用域密文封存与「捧场正循环」电量/冷却反馈）。群聊使用公开人设，好感度只影响可用互动；小黑屋支持 QQ 与 <platform>:<user_id> 统一屏蔽/解封。
作息与主动行动
世界状态记录清醒、休息与精力。LifeBlockPlanner 读取日程与待办，执行时核对共享 SocialScheduleOptions、解耦的 Owner/群聊日限额、目标平台就绪状态与发送窗口，并经 apply_presence 同步状态外显。
预算与用量
付费请求（含 Vertex AI 优先 / Developer API 回退的语义 Embedding）先在 SQLite 中预留，再按返回用量结算；模型、思考档位与 model_work（含 embedding.*、plugin_bus、伴看与语音伴随独立归属）按真实业务维度聚合为 usage.categories（与既有 usage.lanes 总额严格守恒），供运行概览与账本拆细展示。
联网取证
外网检索与链接预览优先委派给 web_tools 容器（公网 IP 钉死与逐跳 SSRF 拦截），离线回退内核；预算与安全审查仍由引擎门卫把关。
模块归档
具备归档授权的模块通过 Drive 同步服务使用指定目录并记录回执；歌单工坊则通过独立的 SongDriveStore 直连 Hakimi_Songs/（严禁触碰 Antigravity_Memory）。
