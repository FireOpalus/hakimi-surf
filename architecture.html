B 站资料与原片分析

获准私聊／群聊→有效 BV→公开资料→来源筛查→分析

群聊观看资格已放宽到正常群聊，不再另要求真实 @；仍须通过群策略、接话门卫并解析出有效 BV。私聊沿用准入规则，安全沙箱和已知外部 Bot 不走此分支。

符合条件后才解析 BV／短链。优先元数据、字幕和公开材料；配置允许且需要视听信息时，走受限下载 → Files API → 视频分析。

原片接受横／竖屏：短边 180–540 px、长边 ≤1280 px；默认 ≤480 秒、≤80 MiB。指定本地下载失败不计成功额度，但总尝试仍有日上限；风控直接退避。多视频取首个有效目标。

外部视频材料与分析摘要不写入聊天历史。

03分层筛查与投递审计

v1.6.1 · 触发资格、文字与轻反应分别追踪

触发层 · 本地判断

先区分接话与看视频

普通用户的私聊、真实 @、顶层昵称点名与已验证引用可构成明确请求，安全放行后跳过自由插话门槛。未获 Owner 邀请的已知 Bot 即使 @ 本机，也必须通过自身接话阈值。

视频仍经 can_watch_video，现允许 group／private 场景；视频链接本身不等于明确请求，不能绕过 at_only 或安全判断。戳到本机的可信通知按直接请求处理。

attention.py · group_pipeline.py · service.py
筛查层 · Decisions

来信与来源／输出分别判断

来信使用运行时阈值；外部来源和生成输出继续使用独立安全阈值。两项安全概率均先解析，达到阈值立即拦截，缺失或畸形数据拒绝通过。

来源／输出的置信度低于配置下限时，再检查是否低于 0.5，或剩余概率质量是否可能触及阈值；任一满足则拒绝，避免仅因低于旧下限误拦有效结果。

04热配置控制流与预算门禁

v1.6.1 · 图片、文件、归档阈值、检索与余额的加密管理

手动余额：校准值 − 后续本地支出

/admin/api/account-balance 保存金额与当时累计支出基线，之后按差额展示剩余余额，最低为 0；校准数据加密存入 admin_config。

这是管理观测，不自动查询供应商，也没有取代原预算门禁；将余额设为 0 本身不等于将日预算设为 0。

旧搜索账目的一次性调整

Store.open 按 search_unbilled_v1 标记，将保留的 search 明细金额／预留归零，并调整相关总额与聚合；原调用次数和 Token 不因此消失。

仅在初始化发现迁移标记缺失时执行；标记存在则跳过，后续搜索按当前零金额口径登记。

05上下文与差量续链

沿用 1.1.4 续链机制 · 逻辑上下文与实际请求载荷分开组织

A

稳定系统前缀

共享指令、公开／Owner 人设、固定协议与静态规则；按可信身份选择。

人设与九字段动作／表情协议固定；群聊和获准私聊（含 Owner）的可用表情标签放 C。增删标签不改 A；协议升级本身仍可能使旧链失效。

persona.py · prefix_runtime.py
B

追加式会话热史

过审用户消息与 ACK 确认的助手回复，按稳定 seq 序列化；格式化时去掉重复的身份前缀。

相邻消息间隔达到 30 分钟时，按 BOT_TIMEZONE 标注时间断点。经过检查的最多 120 字附图摘要在 ACK 后追加为新行，图片字节不进入 B。

session_manager.py · history_lines
C

当轮动态尾窗

时间、核验身份、当前批次、权限、图片来源、文件摘录、搜索及召回。续链按摘要省略未变的背景／表情标签，邻近消息去重窗口最多 16 项。

Owner 专属背景仅在对应私聊加载。可选记忆先让出预算；门卫输入与 C 尾窗默认分别以本地估算的 4,200 Token 限长。

结构化群聊批次

最多 16 条／24,000 字；保留 event_id、发送者 ID、昵称与正文，引用回复可对应到被回应的那条消息。

多图仍补邻近文本

取邻近 6 条群消息，每条最多 160 字；按 event_id 排除 B 和当前批次已有内容。当前两张图片占满时仍补文本。

有界引用与转发展开

主展开路径最多 6 个引用 ID、4 个合并转发，每个转发最多 40 个节点；总展开限 24,000 字，图片仍最多两张；多余图片去重截断并记录状态。

公共链接只补标题与描述

入站预览最多两条链接，总等待预算 1.8 秒；逐跳验证公网地址并固定 DNS，每条最多四次 HTTP 请求。只读有限 HTML 头部，支持有界 gzip／deflate 解码与 Open Graph 兜底；失败留空，不下载整页充当已读材料。

link_preview.py · 入站丰富上下文

C 区按已确认链状态去重

续链保留当前身份、时间和批次；摘要、Owner 背景、双轨召回、表情名单未变化时不重复发送，邻近内容保存最多 16 项摘要用于去重。turns／context_digests／seen_nearby 随 ACK 提交；重新起链恢复完整 C，预算始终按完整逻辑上下文预留。
