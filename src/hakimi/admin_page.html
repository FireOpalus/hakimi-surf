Token 与费用账本

Token 来自 API 返回的 usage。缓存率使用已观测缓存 Token / Interactions 已报告输入；未报告缓存字段时标注为下界，不将其解释为真实零命中。缺失的 Token 明细显示未知。

本账本记录 Gemini 调用；Google Drive 文件同步不计入其中。“历史未归属”是旧版未保存模型和 Token 明细的调用，金额保留，不能据此推断为 Drive 费用。联网搜索次数与 Token 仍可观测，但检索费用已从账本扣账、预算上限与账户余额中排除。

账单估算与熔断口径

调用前仍按最坏上界预留以防并发超支与异常熔断；调用完成后按返回 usage 与配置价格结算估算费用，含已报告的缓存折扣与联网查询费。尚未收到流事件的指定 HTTP 错误释放预留；流中断或超时按可用用量、输出片段和耗时回退估算。未知用量仍标为未知；本地估算不等于 Google 最终账单。

按模型与有效缓存覆盖率

有效覆盖率 = 缓存输入 /（合资格输入 − 2050），仅计输入 ≥6144、非首轮与非截断轮聊天。90% 是稳态观察目标，不是服务保证。旧版本已清理的模型明细无法补造。

按思考档位统计

统计每次模型调用实际下发的 thinking_level（含 auto 动态分档、Carbon 专家档、记忆 Flex 固定 medium 与联网检索固定 medium；Decisions 门卫标为 none，升级前未记录档位的历史调用归入历史未记录）。

全局与分项预算

按 BOT_TIMEZONE 自然日和自然月统计，默认北京时间。单用户与各分项日预算同样按本地自然日生效；设置任一上限为 0 会暂停对应付费调用，0 Token 本地指令和告警不受影响。既有累计总上限（total_usd）仅由 .env 独立生效。

手动填写账户当前可用余额后，系统会在后续非联网 API 消耗产生时实时扣减并展示预估剩余余额；历史账单不会倒扣，联网搜索费用不计入余额扣减。

每日休息时间

按 Bot 时区控制每日休息时段（默认 23:00–08:00）。启用并处于休息时段时，只保留群聊被动上下文并停止 AI 生成、B 站巡逻与主动陪伴消息；撤回通知仍正常处理，热开关与时间修改立即生效（进行中的生成不会中断）。

回复防抖时间

单位为秒，范围 0–30。消息连续到达时重新计时，但不超过最长等待；当前已开始生成的回复不受影响。普通群聊等待或最长等待设为 0 时，全场景关闭合并等待。命令仍即时处理。

请求限流与发送节奏

单用户与全局每分钟限流及待处理队列容量立即生效；超出限流的消息在入队前静默忽略。拟人发送延迟范围 0–10 秒，且最长延迟不得小于最短延迟。

图片尺寸与智能压缩

先按原图大小和总像素上限放宽接收，再在本地按 Lanczos 缩放为高清 JPEG 发给模型，编码目标 ≤800 KiB，复杂图片仍可能超过；常规／16:9 截图默认长边 ≤1600px、长截图默认 ≤2560px，长宽比 ＞4.5 的超长图在空余槽位充足时沿长轴自动切为两张带重叠的高清切片。
