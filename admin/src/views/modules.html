模块动作

Colab 云端算力与 Worker 状态

主脑通过 loopback HTTP + Bearer 鉴权调度独立进程外 Colab 通用 GPU Worker（禁止主脑直接读取 Colab 凭据）；GPU 选型与允许卡白名单由各业务模块按作业自主声明，不设每日次数/CU 上限，保留单作业超时、孤儿清退与队列上限 20 防失控护栏。

危险操作立即释放所有 Colab 运行时（含热保活会话），执行中的作业会失败。

GPU 选型由各业务模块按作业声明，不设每日作业次数与每日 CU 上限；仅保留单作业默认超时、孤儿会话清退与队列长度上限 20 三道防失控护栏。
